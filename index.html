Tentang saya

Dari kelas 10 sampai 12, saya belajar membangun aplikasi mulai dari game sederhana sampai sistem berbasis web yang menyimpan data di database.

Saya bersekolah di jurusan Rekayasa Perangkat Lunak SMK Bina Mandiri Multimedia, Cileungsi. Saya senang merapikan alur kerja yang berantakan menjadi tampilan yang jelas, dan terbiasa bekerja disiplin dengan tenggat waktu serta bekerja dalam tim.

Selama PKL enam bulan di UPT Pajak Daerah Gunung Putri, saya mengerjakan administrasi data pajak setiap hari, lalu membangun aplikasi eSPPT untuk membantu pekerjaan itu.

Pengalaman PKL

UPT Pajak Daerah Gunung Putri, Bappenda Kabupaten Bogor. 15 Januari sampai 15 Juli 2026.

  1. Administrasi dan data awal

    Memilah lembar SPPT PBB berdasarkan desa, lalu merekap potensi pembayaran dan calon wajib pajak baru memakai Microsoft Excel.

  2. Input data di aplikasi P-Man

    Memasukkan data SPPT ke sistem web P-Man milik Bappenda dan membantu memutakhirkan data objek serta subjek pajak.

  3. Pelayanan lapangan

    Ikut Mobil Perpajakan Keliling ke desa, mengantar SSPD ke restoran, dan membagikan SKPD ke perusahaan di wilayah kerja.

  4. Hasil terapan: aplikasi eSPPT

    Merancang sistem input data SPPT berbasis web dengan login, dashboard, data SPPT, form input dengan foto lembar SPPT, dan halaman profil.
